# Extreme Intelligent Pest Control — Homepage Prototype

Open `index.html` directly in a browser, or run the small Node.js server:

    npm start        # → http://localhost:3000

Stack: HTML5 · Bootstrap 5.3.8 + Bootstrap Icons (CDN) · pure CSS (css/style.css) · vanilla JS (js/main.js) · Node.js static server (server.js, no dependencies).
Images are hot-linked from Pexels. All phone numbers, emails, addresses and reviews are placeholders.
